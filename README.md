# 新楓之谷公告懶人包

在本機查閱台灣《新楓之谷》官方活動公告、搜尋獎勵取得方式，並把重要期限匯出到日曆。網站使用 Node.js 24，將公告 HTML 保存為來源快照，並以本機 JSON 保存整理結果。

## 安裝與啟動

```powershell
npm ci
node --env-file-if-exists=.env src/start.mjs
```

啟動後開啟終端顯示的網址，預設為 [http://127.0.0.1:3181](http://127.0.0.1:3181)。可用環境變數 `PORT` 指定連接埠。要使用 Gemini 整理摘要或查詢，請參照 `.env.example`，在專案根目錄的 `.env` 設定 `GEMINI_API_KEY` 與 `GEMINI_MODEL`。

第一次使用可從「公告管理 → 公告探索」貼上官方版本公告網址並保存來源。公告管理也提供「匯入並整理公告 19129」的快捷入口。收錄後可搜尋「核心寶石」，點「查看取得方式」，從活動筆記核對資格、步驟、上限和期限。已保存的結果可離線查閱。

## 首頁與活動筆記

- **活動一覽**預設顯示進行中或仍可領獎的主活動。桌面每排兩張卡，手機改為單欄。卡片顯示子活動數量，展開後可點名稱直達活動筆記。
- **近期截止**以主活動名稱顯示。同一主活動下，截止時間和種類相同的子活動合併一列，可展開查看。參加截止、領獎截止、效果到期及已知的補完截止依各自期限顯示。日期採 `MM/DD HH:mm`，僅知日期時顯示 `MM/DD`。
- **全部活動**依主活動分區，包含已結束的活動。首頁可依名稱、狀態、獎勵類型或關注項目查找，並在活動筆記核對適用條件及來源段落。
- **外觀**可選跟隨系統、淺色或深色，瀏覽器會記住選擇。日曆色條有清楚的邊線與文字標籤。

公告明列子活動專屬的領獎期間、效果到期或限時補完規則時，會在對應項目標示。像「12/02 維護後」會保留原文和日期，確切時刻維持未知。

## 回歸測試

```powershell
node --test
```

測試使用本機 HTTP、替代公告來源、模擬模型回應及固定時間，驗證匯入、活動期間、搜尋、日曆匯出與備份還原等流程。公告快照、整理結果及可取得的模型用量存在本機 `data/`。Git 排除 `data/` 與 `.env`。

## 公告拆分與核對

程式根據正文容器、標題、分隔線、日期及資格判斷活動和子活動的歸屬，並保留原文、表格與圖片的位置。共用條件按適用範圍引用，子活動獨立的日期及資格優先。已核對的規則與公告案例見 [公告拆分規則](docs/notice-splitting-rules.md)。

歸屬不明時可在拆分核對頁檢視原文，選擇活動、取得方式及適用段落。頁面若顯示「用 Agent 分析待確認的歸屬」，可取得附原文段落編號的建議，再人工確認並保存。

需要整理摘要時，從活動筆記展開「摘要整理」，按「用預設模型整理這個方法」。模型收到指定方法及適用的共用段落，摘要中的來源可回查原文。

## 玩家 Agent 查詢

1. **問這個活動**。從活動筆記選「玩家查詢」，展開「問這個活動」。例如在「搖滾樂園粉絲俱樂部招募」問「選燃燒之城應援時 Lv259，現在 Lv260，本週獎勵看哪一級？」點回答後的依據，可展開原文或表格。
2. **比較兩種取得方式**。從同一區點「比較兩種取得方式」，選「燃燒之城應援」與「墮落雷霆應援」，查看並排的資格、方式、獎勵、限制與成本。也可選不同活動的方法。
3. **自然語言搜尋**。首頁先搜尋「那個烤章魚的椅子怎麼拿」。名稱搜尋零筆或超過八筆時，按「用 Agent 搜尋」取得已收錄的候選及取得方式連結。活動狀態和獎勵類型篩選也會套用。

這些功能在送出後使用「公告管理 → 來源與摘要更新」設定的預設模型（Gemini 或本機訂閱 Codex）。網站會將提問或搜尋句送至該模型，結果只在當次頁面顯示。公告筆記、表格及名稱搜尋可直接查閱。

官方圖片有文字或數值時，從活動筆記展開「官方圖片來源與選圖」，預覽原圖，並展開「圖片辨識 · 待人工核對」。對照原圖編修辨識稿後，按「核對並加入活動筆記」。筆記會顯示核對文字及原圖，之後「問這個活動」也能引用。圖片換版後需重新核對。

## 回溯官方公告

在上方「公告管理」分頁點「公告探索」，再按「檢查官方公告列表」。網站以台北日期回溯最近 90 天，顯示已保存來源、待確認版型及擷取失敗的項目。較舊的官方公告可從同頁貼網址補入。

待確認的版本公告可以先讀原文及表格，再指定活動名稱、取得方法和適用段落。確認後可從首頁搜尋該活動，並在活動筆記手動整理摘要。例行公告和已收錄活動的相關異動會附來源供核對。

「活動來源追蹤」列出各來源的追蹤原因，並提供手動重查。「每日更新排程」預設台北時間 14:10，程式運行且電腦清醒時會自動更新，恢復後可補查最近一次錯過的排程。「批次進度與重試」可繼續待處理來源或單獨重試失敗項目。

## 活動日曆與備份

在「活動日曆」點選日期可查看當日開始、截止、開領、領獎截止、效果到期與補完項目。已辨識的時間點可匯出為 `.ics`，並可另選有官方時刻的每日或每週重置提醒。時刻未知的日期以全天事件匯出。活動日期或提醒規則變更後，網站會提示重新匯出，舊事件可在外部日曆管理。

「備份與還原」可下載本機資料的 JSON 備份，也可選檔後確認還原。還原會校驗檔案，將網站切換到該備份的資料版本，原本資料目錄留存。備份包含已保存的來源、圖片、摘要、人工拆分、個人修正、關注、問題來源、日曆匯出紀錄、排程與模型途徑。請在另一環境重新設定 API 金鑰或登入 Codex。
