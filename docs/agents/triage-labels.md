# 分類標籤

技能提到分類角色時，在工單的 `Status:` 欄位使用對應的標籤。

| 分類角色 | 工單標籤 | 用途 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格已足夠，可交由代理執行 |
| `ready-for-human` | `ready-for-human` | 需要由人員執行 |
| `wontfix` | `wontfix` | 已決定不處理 |
