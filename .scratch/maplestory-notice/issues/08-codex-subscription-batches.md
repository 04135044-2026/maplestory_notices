# 08: 用訂閱Codex整理指定批次並切換預設

**What to build:** 從網站將指定工作改用現有訂閱登入的Codex，含圖片與可查閱結果；批次完成回原預設，也可明確修改長期預設。

**Blocked by:** 07：區塊更新與共用條件影響追蹤

**Status:** ready-for-agent

**Completion:** done

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-031、US-032、US-033；D7、D12、D13、D14；AC13、AC14、AC23。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 真實驗證本機訂閱登入、文字／圖片、可使用的結構化整理與網站呈現，不代以API key計費。
- [ ] 單批切換不更改長期預設；明確修改預設才持續生效。
- [ ] 登入／額度失效或無效輸出保留工作與舊結果，不自動買額度，不能取得的用量不捏造。
- [ ] 沿用已指定區塊、圖片及共用條件，Codex不另行決定活動邊界。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。
