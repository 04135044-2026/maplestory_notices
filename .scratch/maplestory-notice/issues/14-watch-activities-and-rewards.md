# 14: 關注活動獎勵與站內更新提示

**What to build:** 可關注活動或獎勵並在我的關注及篩選中查看；相關來源更正後顯示站內提示。

**Blocked by:** 06：首頁篩選及從獎勵反查活動；09：合併多來源與顯示官方更正差異

**Status:** ready-for-agent

**Completion:** ready for player acceptance

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-020、US-021；D1、D8；AC07、AC21。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 關注對應穩定項目，重新整理、重新命名與重啟後仍保留。
- [ ] 只有受影響項目顯示更新提示，關注不代表符合資格、已完成或已領獎。
- [ ] 可依是否關注篩選，離線可讀已保存關注。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。

## Comments

- 本機 HTTP 測試關注三眼章魚活動與椅子、首頁只看關注篩選，再新增有依據的官方更正。兩個受影響項目顯示來源更新，12 項測試通過。
- 活動以穩定活動 ID 保存，獎勵以活動、方法、獎勵名稱及組別保存。來源暫時無法對應時，仍保留關注紀錄供離線查閱。
