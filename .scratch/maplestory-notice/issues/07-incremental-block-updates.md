# 07: 區塊更新與共用條件影響追蹤

**What to build:** 手動更新偵測文字、圖片、區塊及共用條件變更，只重新整理受影響內容，保留舊結果與正確時間。

**Blocked by:** 04：整理圖片表格並呈現官方獎勵外觀

**Status:** ready-for-agent

**Completion:** pending

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-018、US-026、US-028、US-030；D5、D6、D11、D12、D14；AC08、AC12、AC18、AC29、AC30。 補充 AC34；D15。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 來源已更新且摘要待重整時，分別呈現狀態與時間，仍可讀舊摘要；重整操作在公告管理。

- [ ] 相同內容重抓後不再次交給模型；同網址圖片內容變更能觸發整理。
- [ ] 保存新舊來源快照；來源取得與摘要完成時間分別顯示。
- [ ] 失敗不清空舊內容或假稱摘要已更新，原快照與已保存圖片可離線查閱。
- [ ] 只重整變更與受影響區塊；共用資格、限制或圖片改變時所有適用方法皆更新。
- [ ] 快取區分區塊、共用條件、模型、提示與拆分規則，不誤用舊結果。
- [ ] 模板失效時標示拆分待確認，保留舊資料與人工歸屬，不自動整頁LLM拆分。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。
