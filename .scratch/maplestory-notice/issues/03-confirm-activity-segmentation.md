# 03: 檢視並調整待確認的活動拆分

**What to build:** 網站可檢視未知模板或拆分不足的原文／圖片，人工指定活動與方法邊界及共用條件，確認後再摘要。

**Blocked by:** 02：依頁面模板拆分多活動與取得方法

**Status:** ready-for-agent

**Completion:** done

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-003、US-004、US-013、US-014；D1、D2、D14；AC27、AC28。 補充 AC33、AC34；D15。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 拆分檢視與調整位於公告管理，從待確認工作可找到對應活動或來源；公告未載明與拆分待確認呈現各自原因。

- [ ] 保留完整來源，待確認部分明示，已成功區塊仍可查。
- [ ] 可人工調整邊界、歸屬與共用條件，保存對應並於重啟後保留。
- [ ] 未確認內容不交LLM重組活動，確認後只整理指定內容及必要上下文。
- [ ] 人工拆分與摘要欄位修正分開呈現，來源變更可提示受影響人工歸屬。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。
