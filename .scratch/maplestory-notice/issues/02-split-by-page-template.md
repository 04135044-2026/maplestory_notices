# 02: 依頁面模板拆分多活動與取得方法

**What to build:** 程式依已驗證模板拆分活動、取得方法及共用條件，LLM僅提取指定內容與摘要，網站可逐項核對獎勵和限制。

**Blocked by:** 01（使用者已確認首輪查閱）

**Status:** ready-for-agent

**Completion:** pending

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-003、US-004、US-008、US-009、US-010、US-011；D1、D2、D14；AC02、AC03、AC04、AC06、AC27、AC28。 補充 AC33、AC35；D15。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 以 19129 核對主活動、子活動、方法、補充說明及共用條件；核對椅子兩種達成門檻、消除壓力的獨立日期、幸運箱為可能獎勵。重要欄位可回查段落，預設畫面以玩家決策所需資訊為主。

- [ ] 以代表公告驗證容器、標題、分隔、表格規則，區分活動和取得方法，不以每個標題代表一個活動。
- [ ] 共用資格、期間、注意事項與圖片保留適用範圍，模型只整理指定區塊與適用上下文。
- [ ] 來源與區塊可核對，輸出含資格、步驟、獎勵、成本、機率、付費與限制，未知不補造。
- [ ] 未知模板或疑似遺漏標示拆分待確認並保留全文，不整頁交LLM拆分。
- [ ] 保存可重現模板規則、版本及來源對應，標題或順序變更不使項目身分遺失。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。
