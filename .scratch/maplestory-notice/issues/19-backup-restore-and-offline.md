# 19: 備份還原完整本機資料並離線核對

**What to build:** 從網站備份與還原來源快照、圖片、整理結果、問題資料、關注及修正，重啟或離線仍能查閱。

**Blocked by:** 08：用訂閱Codex整理指定批次並切換預設；14：關注活動獎勵與站內更新提示；15：修正摘要、保留個人修改及還原；17：週期提醒及來源更正後重新匯出提示；18：已知修復問題清單及活動關聯

**Status:** ready-for-agent

**Completion:** ready for player acceptance

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-036、US-037；D8、D9、D10、D11、D14；AC18、AC19。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 以實際備份在乾淨本機資料環境還原，核對來源、圖片、差異、個人修正及關注皆保留。
- [ ] 備份不包含API金鑰或Codex登入資料；還原後需重新設定憑證。
- [ ] 匯出提示與模型途徑設定等持久資料不因還原造成錯誤聲明；記錄保存範圍與操作方式。
- [ ] 備份還原保留人工拆分、來源區塊與共用條件關係。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。

## Comments

- 從網站下載包含 77 個檔案的實際備份，透過上傳還原到空的本機資料目錄，關閉並重啟網站。在停用外部取得與模型呼叫的環境確認活動原文、圖片位元組、問題、人工拆分、個人修正、來源更正、關注及匯出提示。
- HTTP 測試驗證下載只含受支援的資料、排除憑證、拒絕不安全檔案路徑，並確認重啟後仍保留關注與排程設定。
