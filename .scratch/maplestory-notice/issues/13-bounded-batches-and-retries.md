# 13: 受控批次、失敗重試與待處理工作

**What to build:** 網站顯示批次處理進度與可重試項目，有限次重試，額度不足時保留工作，避免回溯大量公告無限制呼叫。

**Blocked by:** 10：回溯180天並發現新的相關公告

**Status:** ready-for-agent

**Completion:** pending

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-028、US-031；D6、D7、D12、D13、D14；AC12、AC13、AC30。 補充 AC34；D15。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 工作列表標示影響的活動、缺少內容及下一步；可重試單項並保留舊摘要。

- [ ] 區分來源失敗、圖片不足、模型無效及額度不足，保留已成功工作與舊摘要。
- [ ] 提供批次限制及手動重試；重試次數、間隔與上限由實測決定並記錄。
- [ ] 額度不足不無限重試或自動使用收費途徑；保留工具可取得用量，未知量明示未知。
- [ ] 工作依已確認區塊及受影響範圍處理，拆分待確認與模型失敗分開呈現。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。
