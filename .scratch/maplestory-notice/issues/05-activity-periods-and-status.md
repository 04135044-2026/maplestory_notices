# 05: 區分活動期限與顯示活動狀態

**What to build:** 網站分開顯示參加、開領、領獎與重置規則，依台灣時間呈現狀態，保留維護前後等原文。

**Blocked by:** 01（使用者已確認首輪查閱）

**Status:** ready-for-agent

**Completion:** done

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-010、US-012、US-013、US-022；D2、D3、D13；AC03、AC11、AC16。 補充 AC33、AC35；D15。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 用 19129 的消除壓力測子活動日期優先、缺時刻的邊界與有效區間；領獎時間缺漏時不以參加截止代填。

- [ ] 以不同參加／領獎期限的來源驗證活動結束後仍可顯示可領獎。
- [ ] 無可靠年份／日期／時間時標示不足，不猜時刻；各方法截止情況不被單一活動狀態掩蓋。
- [ ] 時間可替換的整體測試檢查未開始、進行中、可領獎、已結束與待確認。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。
