## Acceptance criteria

- [x] 先以公告 19129 的粉絲俱樂部做預設畫面文字示意圖，展示找獎勵、查期限和回看官方公告的入口，供使用者確認後實作。
- [ ] 從空白本機資料匯入 19129 並整理指定活動。首頁最小名稱搜尋可查「核心寶石」，直達相應活動與方法；按規格腳本核對資格、第一步、限制、參加期間及領獎期限狀態。
- [ ] 以該版本啟動網站，記錄版本、網址、人工核對及官網對照的方式。交付後等使用者確認流程，再開始後續任務；若較慢或答案有誤，先修正本票。

- [ ] 一份文字為主且模板已驗證的官方公告，經程式擷取與指定區塊、真實Gemini提取後在本機網站可核對；模型不決定活動邊界。
- [ ] 重要欄位能定位來源段落；未知資格或時間不推測。
- [ ] 空白、斷線、額度不足、輸出無效分別呈現，保留已保存資料，不切換收費方式。
- [x] 記錄首個可執行的網站、持久保存及測試選型和啟動方式；憑證與本機生成資料排除於 Git，規格與任務保留。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。
