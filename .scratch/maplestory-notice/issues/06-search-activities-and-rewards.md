# 06: 首頁篩選及從獎勵反查活動

**What to build:** 以活動卡片瀏覽，按活動／獎勵名稱搜尋及狀態／類型篩選，從外觀與獎勵結果查到各取得方法。

**Blocked by:** 04：整理圖片表格並呈現官方獎勵外觀；05：區分活動期限與顯示活動狀態

**Status:** ready-for-agent

**Completion:** pending

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-002、US-005、US-006、US-021；D1、D2、D3、D5；AC02、AC21。 補充 AC32、AC33；D15。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 在首張票最小搜尋上補齊跨活動搜尋與原票篩選。從首頁搜尋三眼章魚椅子，依 19129 腳本驗收；零結果說明收錄範圍，已結束活動仍可查。重測未讀過的同類案例。

- [ ] 首頁優先顯示未開始、進行中與仍可領獎活動；已結束仍可搜尋。
- [ ] 獎勵結果顯示已確認圖片或缺圖提示，連到正確活動、資格、方法及期限。
- [ ] 以網站操作驗證名稱、類型及狀態篩選，保留版本來源脈絡。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。
