# 16: 網站日曆與選取活動匯出

**What to build:** 在網站日曆查看活動與領獎日期，勾選活動匯出含開始、截止及領獎截止的ics。

**Blocked by:** 05：區分活動期限與顯示活動狀態

**Status:** ready-for-agent

**Completion:** ready for player acceptance

**Specification:** [正式規格 v1.2](../../../SPEC.md)；US-022、US-023、US-024；D3、D9；AC16。 補充 AC33、AC35；D15。

**Decision:** 遵循 SPEC.md D14：程式依已驗證模板／人工確認拆分；LLM 僅處理指定內容的提取、圖片辨識與摘要。

## Acceptance criteria

- [ ] 先以 19129 與重疊主活動情境畫示意圖，確認近期安排、參加與領獎標記及主子活動資訊量。用 19129 核對筆記與日曆日期一致；確認示意後實作。

- [ ] 只匯出選取活動，日期用全天事件，可靠時刻才用時間事件。
- [ ] 維護後有確定日期則以全天加原文，日期未知列為無法匯出並說明。
- [ ] 輸出含產生時間與活動／來源說明，實際解析匯出結果驗證台灣時間與期限。

- [ ] 經網站操作或實際輸出驗證上述交付行為；依已確認的整體入口，以保存來源、可替換模型回應及時間建立適用的可重複驗證。既有相關驗證仍通過。

## Scope and verification

本任務引用的故事與驗收條件可能由多張任務共同完成；本張負責範圍以上述交付行為及核取項目為準，不將其他任務尚未完成的功能當成本張完成證據。

完成時記錄使用的來源案例、實際操作／驗證結果及尚存限制。涉及真實模型呼叫時，記錄可取得用量；未知量明示未知。前置任務未完成時保持等待，不以 ready-for-agent 標記取代依賴檢查。

## Comments

- 使用者確認月曆示意，同日重疊項目各占一行，標明主活動、子活動及開始、截止、領獎截止。
- 以 19129 範例透過 HTTP 開啟月曆並選取三眼章魚活動。解析 .ics 確認 10/21 全天開始、測試更正的台北 12/08 23:59 換算為 15:59 UTC、活動與官方來源、產生時間及 UTF-8 換行。12 項測試通過。
